## English

### About

Salati adds prayer times to the Omarchy bar. Click the crescent moon to see today's schedule and a countdown to the next prayer. It supports Arabic and English, automatic or manual location, several calculation methods, and both Standard and Hanafi Asr settings. Prayer times are fetched from AlAdhan; local calculation is available offline or if the service cannot be reached.

### Install

```sh
omarchy plugin add https://github.com/muhamedwalied/Salati-Plugin.git --enable
```

### Remove

```sh
omarchy plugin remove muhamed.salati
```

## العربية

### عن الإضافة

تضيف «صلاتي» مواقيت الصلاة إلى شريط Omarchy. اضغط على الهلال لعرض جدول اليوم والعدّاد للصلاة القادمة. تدعم العربية والإنجليزية، وتحديد الموقع تلقائيًا أو يدويًا، وعدة طرق لحساب المواقيت، وخياري العصر: العادي والحنفي. تجلب الإضافة المواقيت من AlAdhan، ويمكنها حسابها محليًا عند عدم توفر الإنترنت.

### التثبيت

```sh
omarchy plugin add https://github.com/muhamedwalied/Salati-Plugin.git --enable
```

### الإزالة

```sh
omarchy plugin remove muhamed.salati
```
